**`ats-engine check --job-url <url>` reads a job posting on Greenhouse, Lever or Ashby** from the board's public JSON API, so a posting no longer has to be saved first: `ats-engine check resume.pdf --job-url https://job-boards.greenhouse.io/acme/jobs/123`. It reads the posting's title and description, and the employer's name, left out of the keywords as it is for a saved `.html` page: Greenhouse's, or, as Lever's and Ashby's APIs name none, the board's name in the link. A Greenhouse posting is read from its board page, its `?gh_jid=` link or the embed a careers page frames (`/embed/job_app?for=…&token=…`). A Greenhouse or Lever posting adds that ATS's documented notes to the advice, as `--ats` does, unless `--ats` names another. The CLI asks only the API host listed for the posting's host (`boards-api.greenhouse.io`, `api.lever.co`, `api.eu.lever.co`, `api.ashbyhq.com`), never the host in the URL; it takes `https` addresses only, follows no redirect, waits at most 20 seconds and reads at most 20 MB. A posting on any other site, or on Greenhouse's EU boards (which have no public API), is refused with a message to save the page and pass it with `--job`; `--job` and `--job-url` together are refused. The engine's core, `/job`, `/node` and the MCP server still make no network calls, and scores and recovered fields are the same for every input.
