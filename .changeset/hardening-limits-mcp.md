`job_path` must name a `.txt`, `.md`, `.html` (`.htm`), `.pdf` or `.docx` file; any other is refused with a tool error before it is opened. A posting's words come back as missing keywords, so a credentials file named as the posting was echoed to the assistant. PDF reading stops after 100 pages, and a DOCX's headers and footers share one 2 MB budget, so a file padded with empty pages or headers costs what a resume does. A PDF's images are decoded a page at a time rather than all after the file has been read; an image still has no size cap, so a file with large images can hold gigabytes and take tens of seconds.
