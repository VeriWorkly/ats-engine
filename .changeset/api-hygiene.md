**Breaking:** a policy from `parseAtsPolicy` or `withLocales` is now frozen, all the way down, and so are `DEFAULT_POLICY` and every other object the package exports (the locale packs `de`, `hi`, `US`, `DE`, `IN` and `BUILT_IN_LOCALES`, `atsLanguagePackJsonSchema`, `atsRegionPackJsonSchema`, `CONVERT_GROUNDING_SKIP`, `DOCUMENT_LIMITS`, `VERDICT_BANDS` and `/format`'s labels and bands). A host that changes one now gets a `TypeError` in strict mode (every ES module is strict), where before the change was made. The engine caches what it compiles from a policy against the policy object, so a policy changed after its first use was read with the patterns compiled before the change. To change a policy, copy it (`structuredClone`), edit the copy and parse it again. Scores and recovered fields are the same for every input.

- **A policy nested past 5,000 levels is refused with `AtsPolicyError`**, as is one that contains itself, where before it overflowed the stack with a `RangeError`. Any real policy nests about six levels, and the old recursion overflowed somewhere between 2,000 and 7,000.
- **Optional options and inputs accept `undefined`.** Each optional property a host sets (`AtsCheckOptions`, `AtsFileInfo`, `AtsLayoutSignals`, the `/document` types, the `withLocales` packs, `createAtsAi`'s options and routes, a call's options, the adapters' and `HttpOptions`, `LlmResponse` and `LlmUsage`, the tasks' inputs, `readResumeFile`'s options) is now typed `name?: T | undefined`, so a host compiling with `exactOptionalPropertyTypes` can pass a value that may be absent, as the README's examples do (`jobCompany: extractJobPosting(html)?.company`). The engine already read `undefined` as absent. Types the engine hands to the host (a provider's `LlmRequest`, `fetch`'s init, a report) are unchanged. `npm run smoke` now compiles the README's and LOCALES.md's TypeScript samples with that flag on.
- **Smaller bundles for a host that imports only part of `/locales` or `/ai`.** The packs' JSON Schemas and the AI tasks' JSON Schemas are built when their module loads; those calls are now marked `/* @__PURE__ */`, so a bundler drops them, and zod's JSON Schema writer, when nothing imports them. `withLocales` alone bundles to about 48.1 KB gzipped instead of 54.5, and `/ai`'s prompts and error alone to 9.2 KB instead of 16.3. A bundle of the whole subpath is the same size as before.
